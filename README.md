# YOLO 学習画像データ拡張

Windows向けのPySide6 GUIです。640×640のJPEG/PNG画像に回転、左右・上下反転、明度変更、ガウスノイズをランダムに適用し、対応するYOLO形式ラベルを出力します。

## ファイル構成

```text
outputs/
├── main.py
├── requirements.txt
├── README.md
├── src/yolo_augmenter/
│   ├── __init__.py
│   ├── engine.py       # 画像変換、座標変換、出力
│   └── gui.py          # PySide6 GUIとバックグラウンドワーカー
└── tests/test_engine.py
```

## インストール

Python 3.10以降をインストールしてください。PowerShellでこのフォルダに移動し、仮想環境を作って依存関係を入れます。

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## 起動

```powershell
python main.py
```

## 使い方

1. 入力画像フォルダ、ラベルフォルダ、出力フォルダを選びます。
2. GUIで変換機能と強度、元画像1枚あたりの生成枚数、乱数シードを設定します。
3. 入力画像を選択すると、元画像と最小・元・最大明度のプレビューを確認できます。これらはラベルTXTがなくても表示します。変換プレビューには同名のラベルTXTが必要で、ボックスとクラスIDを描画します。
4. 「生成開始」を押します。停止を押すと現在の画像とラベルの保存を終えてから止まります。

入力画像とラベルは別フォルダに置き、同じベース名にしてください。対応拡張子は`.jpg`、`.jpeg`、`.png`です。日本語を含むフォルダ名とファイル名も読み込めます。ラベルファイルはUTF-8のYOLO形式で、各行を`class_id x_center y_center width height`とします。画像サイズは640×640、クラスIDは0以上、座標とボックス全体は0～1の範囲である必要があります。空のTXTはラベルなし画像として扱います。

出力は指定したフォルダ直下の`images/`と`labels/`に作成されます。既存ファイルを上書きせず、元画像ごとに連番を続けます。各画像はJPEG品質95で保存します。

回転では画像とボックスに同じアフィン変換を使い、オブジェクト自体を余分に拡大せずに回転後の四隅を囲む軸平行ボックスへ変換します。画像の四隅は端の画素を反射して埋めます。回転した矩形の外接範囲が元より広くなる分はYOLO形式の軸平行ボックスに必要な増加です。ボックスが1つでも画像外にはみ出す候補は全体を破棄し、設定回数まで再試行します。上限まで有効な候補を作れない出力はスキップし、ログに理由を残します。すべての変換がOFF、または実質的に変換なしになる設定は受け付けません。

同じ入力、設定、シード、依存ライブラリ版で同じ変換を再現できます。JPEGファイルも同じ環境ではバイト単位で一致します。

## テスト

```powershell
python -m unittest discover -s tests -v
```

単体テストでは左右・上下反転、90度回転、回転と反転の組み合わせ、ボックス範囲外の棄却、明度・ノイズ時の座標維持、クラスID保持、出力サイズと画像・ラベルの対応、乱数シードの再現性、停止後のペア保存を確認します。
